# 📋 Дополнение: HTTP Status Codes для всех endpoints

## Стандартные коды ответов

### 2xx - Успешные ответы
- **200 OK** — Запрос успешно обработан (GET, обновление)
- **201 Created** — Ресурс успешно создан (POST)
- **204 No Content** — Успешно обработано, без содержимого (DELETE)

### 4xx - Ошибки клиента
- **400 Bad Request** — Неверный формат запроса (невалидные параметры, JSON синтаксис)
- **401 Unauthorized** — Требуется аутентификация (нет JWT токена / истек)
- **402 Payment Required** — Недостаточно средств для операции
- **403 Forbidden** — Недостаточно прав (напр., User пытается вызвать /admin/...)
- **404 Not Found** — Ресурс не найден (рынок, ордер, пользователь)
- **409 Conflict** — Конфликт состояния (напр., закрытый рынок, дублирующееся письмо)
- **422 Unprocessable Entity** — Логические ошибки (deadline в прошлом, некорректный исход)
- **429 Too Many Requests** — Превышен rate limit

### 5xx - Ошибки сервера
- **500 Internal Server Error** — Непредвиденная ошибка сервера
- **502 Bad Gateway** — Сервис недоступен (timeout, crash)
- **503 Service Unavailable** — Сервис временно недоступен (maintenance)

| Статус | Описание |
