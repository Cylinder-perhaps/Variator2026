# 📖 Инструкция по загрузке в Яндекс Wiki

Все файлы подготовлены и готовы к копированию. Следуйте инструкции ниже:

---

## 🆕 Создание пространства в Яндекс Wiki

1. Перейти на https://wiki.yandex.ru/
2. Нажать **"Создать пространство"**
3. Заполнить:
   - **Название:** `Variator2026`
   - **URL-адрес:** `variator2026`
   - **Описание:** `Документация проекта крауд-прогнозирования`
   - **Видимость:** `Для моей организации`
4. Нажать **"Создать"**

## 📝 Загрузка страниц

Для каждого файла ниже:

### 1️⃣ **01-HOME.md → Home (главная)**

1. В Яндекс Wiki нажмите на кнопку **"Главная"** или редактируйте существующую страницу
2. Нажмите **"Текст"** (если еще в режиме редактирования)
3. Выберите весь текст и удалите
4. Скопируйте текст из файла `01-HOME.md`
5. Вставьте
6. Нажмите **"Опубликовать"** или **"Сохранить"**

### 2️⃣ **02-GETTING-STARTED.md → Новая страница "Быстрый старт"**

1. Нажмите **"Добавить"** → **"Страница"**
2. **Название:** `Быстрый старт`
3. Нажмите **"Текст"**
4. Скопируйте весь текст из `02-GETTING-STARTED.md`
5. Вставьте
6. Нажмите **"Опубликовать"**

### 3️⃣ **03-ARCHITECTURE.md → Новая страница "Архитектура"**

## 🔗 Связывание страниц (опционально)

После загрузки всех страниц можно сделать ссылки между ними.

В Яндекс Wiki синтаксис ссылок:
```
[[Название страницы]]
```

Или с текстом:
```
[Текст ссылки](URL или имя страницы)
```

Например:
```
[[Быстрый старт]]        # Автоматически ищет страницу "Быстрый старт"
[[Архитектура|Overview]]  # Текст "Overview" → ссылка на "Архитектура"
```

## ❓ Если что-то не получается

- **Таблицы не рендерятся:** Попробуйте скопировать вручную в Wiki-редакторе
- **Диаграммы не отображаются:** Оставьте как ASCII-арт, это все равно читаемо
- **Ссылки между страницами:** Используйте синтаксис `[[Имя страницы]]`
- **Форматирование нарушено:** Нажмите "Исходный код" и проверьте Markdown
