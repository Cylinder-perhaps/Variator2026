3. СТЕК ТЕХНОЛОГИЙ

В процессе разработки программного обеспечения Variator — платформы для коллективного прогнозирования, где пользователи торгуют акциями бинарных исходов на виртуальной валюте — использовался следующий стек технологий. Он включает современные средства и подходы, обеспечивающие надёжность, удобство централизованного управления и гибкость разработки.

3.1. Клиентская часть

Язык программирования и фреймворк:

TypeScript/JavaScript — используется для создания веб-интерфейса, предоставляющего пользователям и администраторам интерфейс для торговли акциями и управления рынками.

React (опционально) — компонентный фреймворк для разработки интерактивного пользовательского интерфейса.

Библиотеки и средства:

Fetch API / Axios — для выполнения HTTP-запросов к REST API серверной части.

WebSocket — обеспечивает подписку на обновления цен в реальном времени и получение уведомлений о состоянии ордеров.

Chart.js или ApexCharts — визуализация графиков цен, истории торговли и статистики портфеля пользователя.

HTML5 / CSS3 — структурирование и стилизация веб-интерфейса.

Инструменты разработки:

Node.js — среда выполнения JavaScript.

npm или Yarn — менеджеры пакетов для управления зависимостями.

Jest / Vitest — фреймворки для модульного тестирования.


3.2. Серверная часть

Язык программирования:

Go (Golang) — основной язык серверной части. Выбран за счёт высокой производительности, параллелизма (goroutines), встроенной поддержки конкурентных операций и простоты развёртывания.

Фреймворк и архитектура:

Go net/http или Gin/Echo — лёгкие веб-фреймворки для разработки REST API.

Архитектура DDD (Domain-Driven Design) и Clean Architecture — применяются для структурирования проекта. Обеспечивают разделение логики, данных и интеграции, что упрощает тестирование и развитие системы.

Структура проекта:
   cmd/ — точки входа приложения.
   internal/ — внутренняя логика (domain, services, handlers, repositories).
   pkg/ — публичные пакеты (API, общие утилиты).

Сетевое взаимодействие:

REST API — серверная часть предоставляет интерфейс, к которому обращается клиентское приложение и администраторы.

WebSocket — используется для отправки обновлений цен и состояния ордеров в реальном времени.

Формат данных JSON — используется для обмена данными между клиентом и сервером.

Хранение данных:

PostgreSQL — реляционная база данных, используемая для долговременного хранения:
   Профили пользователей и их балансы.
   Открытые рынки и их параметры.
   Ордера и история сделок.
   Позиции пользователей и портфели.

Миграции (SQL) — используются для версионирования схемы БД и её эволюции.

Кеширование и очереди:

Redis — используется для:
   Кеширования часто запрашиваемых данных (книга заявок, цены).
   Реализации потокобезопасного матчинга ордеров через Lua-скрипты.
   Исключение race conditions при одновременных операциях.

Развёртывание и запуск:

Docker — используется для контейнеризации приложения и упрощения его развёртывания в разных окружениях.

Docker Compose — позволяет запускать приложение, PostgreSQL и Redis как связанные сервисы в едином оркестрированном окружении.

nginx — reverse proxy для маршрутизации запросов, кеширования и балансировки нагрузки.

Инструменты разработки:

Go modules (go.mod) — менеджер зависимостей, встроенный в Go.

Makefile — автоматизация часто используемых команд (сборка, тестирование, развёртывание).

Testing (Go testing package) — встроенный пакет для модульного и интеграционного тестирования.


3.3. Дополнительные технологии

Конфигурация:

YAML — формат конфигурационных файлов (local.yaml, OpenAPI спецификации).

API спецификация:

OpenAPI 3.0 — используется для документирования REST API.

oapi-codegen — инструмент для автогенерации Go кода на основе OpenAPI спецификации.

Контроль версий:

Git — система контроля версий для управления исходным кодом.

GitHub — хостинг репозитория и в перспективе работа с pull requests.


3.4. Архитектурные характеристики

Язык серверной части — Go — Производительность, параллелизм, простота развёртывания

БД — PostgreSQL — Надёжность, ACID-гарантии, поддержка сложных запросов

Кеш/Очередь — Redis — Быстрое матчинг ордеров, Lua-скрипты для атомарности

API — REST + WebSocket — REST для синхронных операций, WebSocket для реального времени

Контейнеризация — Docker — Изоляция окружения, повторяемость развёртывания

Gateway — nginx — Маршрутизация, TLS/SSL, балансировка


3.5. Циклы разработки и тестирование

Локальная разработка: Docker Compose для запуска БД и зависимостей.

Автоматизированное тестирование: Go testing + прямые интеграционные тесты с PostgreSQL.

Hot reload (опционально): используется air или аналогичные инструменты для ускорения цикла разработки.

Такой стек обеспечивает высокую производительность, надёжность и удобство, необходимые для платформы, обрабатывающей большое количество ордеров и обновлений цен в реальном времени.
