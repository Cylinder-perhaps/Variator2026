## 📝 Подробное описание ролей

### 🔧 ADMINISTRATOR (Администратор)

**Ответственность:** Управление всей платформой, ее здоровьем, соответствием требованиям.

**Возможности:**
```
1.🏪 Управление рынками
   - Создание нового события (market)
   - Установка deadline, категории, описания
   - Изменение параметров события (если не начата торговля)
   - Удаление события (если спам/нарушение)
   - Бан-лист категорий

2. 🎯 Разрешение исходов (Settlement)
   - Закрытие события (status → CLOSED)
   - Выбор выигрывающего исхода
   - Запуск автоматической выплаты победителям
   - Отмена разрешения (если ошибка)
   - Просмотр аудита разрешений

3. 👥 Управление пользователями
   - Просмотр всех юзеров (таблица)
   - Статистика пользователя (win_rate, ROI, trades_count)
   - Блокировка пользователя (временная или постоянная)
   - Разблокировка пользователя
   - Сброс пароля
   - Выдача роли модератора (delegate)
   - Просмотр всех операций юзера (audit log)

4. 🔍 Monitoring & Analytics
   - Просмотр метрик системы (RPS, latency, errors)
   - Просмотр всех жалоб и флагов на контент
   - Логи ошибок и исключений
   - Статистика платформы (всего пользователей, объема торговли)

5. ⚙️ Конфигурация
   - Изменение параметров платформы (комиссия, лимиты)
   - Управление payment gateway
   - Установка мейнтенанса (downtime)
```

**Endpoint'ы (v2):**
- `POST /api/admin/markets` — создать рынок
- `PUT /api/admin/markets/{id}` — изменить параметры
- `DELETE /api/admin/markets/{id}` — удалить
- `POST /api/admin/markets/{id}/resolve` — разрешить исход
- `GET /api/admin/users` — список пользователей
- `POST /api/admin/users/{id}/block` — заблокировать
- `POST /api/admin/users/{id}/moderator` — выдать модератора
- `GET /api/admin/audit-log` — логи всех операций
- `GET /api/admin/metrics` — метрики системы

---

### 👨‍⚖️ MODERATOR (Модератор-комментатор)

**Ответственность:** Качество контента, соблюдение правил, борьба со спамом и нарушениями.

**Возможности:**
```
1. 🎯 Разрешение исходов (делегирован админом)
   - Закрытие события
   - Выбор выигрывающего исхода
   - Запуск выплаты
   - Просмотр аудита разрешений (только ему)

2. 💬 Управление комментариями
   - Просмотр всех комментариев (с фильтром)
   - ВАЖНО: Модератор НЕ может писать официальные комментарии от платформы
           (только как обычный пользователь)
   - Удаление спама/оскорбительных комментариев
   - Скрытие комментариев от спорных аккаунтов
   - Просмотр истории удаленных комментариев

3. 👥 Управление нарушителями
   - Просмотр флагов/жалоб на пользователей
   - Временная блокировка нарушителя (1 день - 1 месяц)
   - Отправка предупреждения пользователю
   - Просмотр истории нарушений пользователя

4. 📋 Просмотр жалоб
   - Список всех флагов на контент (комментарии, события)
   - Анализ жалоб (спам, оскорбления, манипуляции)
   - Отметить жалобу как "разобрано"

5. 📊 Отчетность
   - Просмотр статистики: сколько спама удалено, блокировок
   - Экспорт отчета о модерации
```

**Endpoint'ы (v2):**
- `POST /api/admin/markets/{id}/resolve` — разрешить исход (делегирован)
- `DELETE /api/admin/comments/{id}` — удалить комментарий
- `POST /api/admin/users/{id}/warn` — предупредить (временная блокировка)
- `GET /api/admin/flags` — список флагов/жалоб
- `POST /api/admin/flags/{id}/resolve` — отметить жалобу разобранной
- `GET /api/admin/moderation-stats` — статистика модерации

---

### 👤 USER (Пользователь)

**Ответственность:** Честная торговля в рамках правил платформы.

**Возможности:**
```
1. 💰 Торговля
   - Покупка акций на события
   - Продажа акций (취め досрочно)
   - Отмена своих ордеров (до исполнения)
   - Просмотр своего портфеля (positions)
   - Просмотр своей истории сделок

2. 💬 Комментирование
   - Написание комментария на событие
   - Удаление своего комментария
   - Просмотр комментариев других (public)
   - Отправка флага на спам/нарушение

3. 👤 Профиль
   - Просмотр своего профиля
   - Редактирование своего профиля (имя, аватар, описание)
   - Просмотр своей статистики (win_rate, ROI, total_trades)
   - Изменение пароля

4. 📊 Просмотр данных
   - Список всех рынков
   - Деталь рынка (название, описание, deadline, исходы)
   - Order book (котировки в реальном времени)
   - История всех сделок по рынку (публичная)
   - Профиль другого пользователя (публичные данные)
```

**Endpoint'ы (v1/v2):**
- `POST /api/orders` — купить/продать акцию
- `DELETE /api/orders/{id}` — отменить ордер
- `GET /api/positions` — мой портфель
- `GET /api/trades/my` — моя история
- `GET /api/me` — мой профиль
- `PUT /api/me` — изменить профиль
- `GET /api/me/stats` — моя статистика
- `POST /api/comments` — написать комментарий
- `DELETE /api/comments/{id}` — удалить свой комментарий
- `POST /api/flags` — отправить флаг (спам, нарушение)

## 🔒 Механизмы защиты

### IDOR (Insecure Direct Object Reference) Prevention
```
Во всех endpoint'ах, где пользователь видит данные другого:
- ✅ GET /api/users/{id}/trades → public only
- ✅ GET /api/users/{id} → public profile
- ❌ GET /api/users/{id}/balance → FORBIDDEN (100% защита)
- ❌ GET /api/users/{id}/positions → FORBIDDEN (100% защита)

Во всех личных endpoint'ах:
- ❌ GET /api/positions → требует auth + проверка своего user_id
- ❌ DELETE /api/orders/{id} → требует auth + проверка своего order
```

### Rate Limiting по ролям
```
User:      100 req/min (100 RPS max)
Moderator: 1000 req/min (1K RPS)
Admin:     unlimited (но логируется всё)
```

### Audit Logging
```
Все действия Admin и Moderator логируются:
- Кто (user_id)
- Что (action: create, delete, resolve, block)
- Когда (timestamp)
- Результат (success/error)
- IP адрес
- User-Agent

Хранится 1 год в compliance целях (ФЗ-152)
```

## 📋 Примеры использования

### Админ создает рынок
```bash
POST /api/admin/markets
Authorization: Bearer <admin_jwt>
Content-Type: application/json

{
  "title": "Выиграет ли AGI создан к 2026?",
  "description": "Прогнозирование события AGI creation",
  "outcomes": ["Да", "Нет"],
  "deadline": "2026-12-31T23:59:59Z",
  "category": "Технология",
  "created_by": "admin"
}

Response: 201 Created
{
  "market_id": "uuid",
  "status": "ACTIVE"
}
```

### Модератор разрешает исход
```bash
POST /api/admin/markets/uuid/resolve
Authorization: Bearer <moderator_jwt>
Content-Type: application/json

{
  "winning_outcome": "Да",
  "evidence_url": "https://example.com/proof"
}

Response: 200 OK
{
  "market_id": "uuid",
  "status": "RESOLVED",
  "winners_payout": 10000.50
}
```

### Пользователь удаляет спам
```bash
POST /api/flags
Authorization: Bearer <user_jwt>
Content-Type: application/json

{
  "type": "spam",
  "target_id": "comment_uuid",
  "reason": "Реклама криптовалюты"
}

Response: 201 Created
{
  "flag_id": "uuid",
  "status": "PENDING"
}
```

## ⚠️ Важные примечания

### ❌ Чего Модератор НЕ может делать
- Создавать рынки (только Admin)
- Удалять рынки (только Admin)
- Менять параметры события (только Admin)
- Записывать официальные комментарии от платформы
- Менять роли других пользователей
- Видеть баланс пользователя
- Видеть приватные данные

### ℹ️ Что Модератор МОЖЕТ делать
- Разрешать исходы (делегирован от Admin)
- Удалять спам в комментариях
- Блокировать нарушителей (временно)
- Смотреть все жалобы и флаги

### 📊 Что видит каждая роль при разрешении события

```
Admin (может видеть всем):
  ├─ Все ордера всех пользователей
  ├─ Все комментарии
  ├─ Статистика торговли
  └─ Audit log кто когда делал

Moderator (может видеть для проверки):
  ├─ Суммарные объемы торговли
  ├─ Комментарии (для проверки манипуляции)
  └─ Список флагов на это событие

User (видит только свое):
  ├─ Свой ордер на событие
  ├─ Свою позицию
  └─ Общественные комментарии (без приватных)
```
